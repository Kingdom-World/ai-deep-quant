# 📊 AI深度量化 — 独立量化分析平台 v2.0

> 📚 **项目性质声明：本项目为个人学术研究项目，不构成投资建议，不涉及实盘交易。**
> 平台数据来自公开财经接口，所有分析、评分与回测结果仅用于学习研究演示，
> 请勿据此进行任何投资操作。

一个独立的量化分析 Web 平台：单端口运行，数据直连公开财经接口，
技术指标、因子评分、策略回测、模拟撮合与站内问答全部本地完成。

## ✨ 功能一览

| 模块 | 说明 |
| --- | --- |
| 🏠 主页 | 主要指数市场概况、我的收藏、今日观察（五因子评分） |
| 📈 量化看板 | 多周期 K 线、均线体系、成交量、MACD、形态标注、实时走势 |
| ⚡ 短期副图 | 分钟级K 线（多市场支持）、均线、最新价标线、缩放 |
| 🧮 量化因子分析 | 五因子模型评分与雷达图 |
| 📈 策略回测 | 均线 / RSI / 买入持有等策略的收益曲线、年化、最大回撤、胜率、交易明细 |
| 💰 模拟交易 | 虚拟资金 + 真实行情撮合：市价/限价单、撤单、持仓与当日盈亏、净值曲线；内置多套自动策略与风控 |
| 💬 智能助手 | 站内问答：个股解读、股票池推荐、使用指南（离线规则引擎，无需联网 AI） |
| 🔧 每日自检 | 定时自动自检：代码扫描 + 前端产物检查 + 接口冒烟测试，报告写入 `reports/` |
| 📚 知识库 | 量化概念与研究方法条目，每条带可核查出处；含出处结构化解析与交叉校验 |

## 🧱 技术栈

- **前端**：Vite + React + TypeScript + ECharts + React Router + Zustand
- **后端**：Node.js + Express（单端口同时提供 API 与静态托管）+ iconv-lite
- **数据源**：公开财经接口（多源自动切换）+ 内存缓存
- **零外部依赖**：无 MCP、无付费 API、无外部 AI 云服务

## 📦 目录结构

```
├── server/     后端服务（API + 静态托管 + 自检调度）
├── src/        前端源码
├── shared/     前后端共享的纯逻辑与单一真相源
├── test/       单元与契约测试
├── tools/      离线工具（知识库校验、出处核验、数据构建等）
├── dist/       构建产物
└── reports/    自检报告
```

## 🔐 关于访问控制

本项目支持站点级登录保护（HTTP Basic Auth），通过部署时的环境变量配置。
**公开部署时必须启用鉴权**——未启用鉴权时，所有管理类视图对任何访问者开放。
部署与运维细节请见项目内的部署文档。

## ⚙️ 本地开发

```bash
npm install          # 安装依赖
npm run build        # 构建前端
npm start            # 启动服务，浏览器访问 http://localhost:3001
# 开发模式（前端热更新 + 代理后端）:
#   终端1: node server/index.cjs
#   终端2: npm run dev
```

测试与质量门：

```bash
npm test             # 单元与契约测试
npm run typecheck    # TypeScript 检查
npm run build        # 构建
```
