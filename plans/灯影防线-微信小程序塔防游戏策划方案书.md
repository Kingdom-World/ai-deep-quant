## 一、产品定位

### 1.1 市场与品类判断

- **形态结论**：项目以**微信小游戏**（游戏类目）发行，而非小程序应用内嵌 H5。游戏类目拥有 wx 开放数据域（好友排行）、分享卡片、激励视频广告等小游戏专属能力，是本方案所有社交与商业化设计的前提。
- 塔防是小游戏 IAA（广告变现）品类的成熟赛道，但同质化严重（"植物式摆格子"换皮居多）。机会点在于：**用一条原创的"光"机制重塑塔防的空间策略**，同时用叙事与阵营选择制造社交货币。
- 竞品参照：《塔防精灵》《保卫萝卜4》（玩法基线）、《无悔华夏》小游戏化尝试（叙事参考）、《黑暗光年》剪影美术（表现参考）。差异化不在数值深度，而在**机制记忆点 + 故事谈资**。

### 1.2 目标用户

| 层级 | 画像 | 诉求 | 占比预期 |
|---|---|---|---|
| 核心层 | 25–40 岁通勤/碎片时间玩家，玩过 3+ 款塔防 | 策略深度、每日目标 | 20% |
| 大众层 | 18–35 岁泛休闲用户，被分享素材吸引进来 | 3 分钟一局、颜值、剧情反转 | 60% |
| 外围层 | 剧情向/美术向用户，为世界观和结局而来 | 收集、阵营认同、结局分支 | 20% |

### 1.3 差异化卖点（按传播力排序）

1. **"光路"玩法**：塔不是各打各的，而是共同绘制一张光之网络——棱镜折射、光线连通、合光成环。布塔即"画光"，一图一解法，天然产生"晒布局"行为。
2. **剪影美学**：敌人是暗色剪影、英灵是皮影戏风格，暖光手绘背景衬托。风格极具辨识度，截图即海报。
3. **阵营抉择**：中后期"守灯会 vs 归夜教"全服投票 + 个人结局分支，制造站队型社交话题。
4. **单局 3–4 分钟、竖屏单手**：完全为小程序碎片场景设计。

### 1.4 首屏黄金 3 秒设计

玩家冷启动后的前 3 秒体验（全部发生在主包内，不等待远程资源）：

```
0.0s  纯黑夜幕，一点火星在画面中央（音效：火镰打火"嚓"）
0.8s  火星被吹亮 → 灯芯"噗"地燃起，暖光 1 秒内漫开，
      照亮整座灯火城池剪影 + 远处压境的暗色兽潮（视觉反差冲击）
2.2s  标题《灯影防线》随光晕浮现，副标题"长夜将至，点灯为城"
2.8s  大按钮【点灯】= 开始；首次点击直接进入第 1 关教学，
      不设注册/登录阻断（用微信静默授权）
```

- **原则**：3 秒内必须完成"黑暗→光"的一次情绪冲击；跳过一切 Logo 串烧。
- 加载兜底：若远程分包未就绪，先以主包内低清占位资源进游戏，资源异步替换。

### 1.5 小程序包体与性能红线

| 约束项 | 红线值 | 说明 |
|---|---|---|
| 主包 | ≤ 4 MB | 引擎核心 + 首关 + 通用 UI + 点灯开场（微信小游戏主包上限，以平台最新政策为准） |
| 总包（含分包） | ≤ 30 MB | 超出部分走 CDN 远程资源 |
| 远程资源 | CDN + 本地缓存 | 按章节分包加载，域名需配置小游戏后台白名单（HTTPS） |
| iOS 内存 | 峰值 ≤ 700 MB，目标 ≤ 400 MB | 低内存机型（iPhone X 级）必须实测 |
| Draw Call | 战斗场景 ≤ 120/帧 | 剪影单位共享材质实现低 DC |
| 帧率 | 中端安卓 ≥ 50 FPS，低端 ≥ 30 FPS | 同屏单位 ≤ 80 只，超出的小怪用合并渲染 |
| 启动到可玩 | ≤ 8 s（4G 网络） | 冷启动 = 主包 + 首个远程包 |
| 字体 | 中文字体子集化 ≤ 1.5 MB | 只打包实际用到的字集，标题用艺术字图片 |

### 1.6 商业模型与关键指标

- **变现结构**：IAA 为主（激励视频：复活、双倍奖励、免费刷新英灵、看广告领"续夜灯油"）；Android 侧小额内购（皮肤/去广告/月卡），iOS 侧受虚拟支付限制只走 IAA。
- **广告点位原则**：绝不打断波次，只在结算与备战期出现；每日自然通关赠送 1 次等值奖励，保证零广告体验可通关主线。
- **北极星指标**：人均日局数。辅助 KPI：

| 指标 | 目标值 |
|---|---|
| D1 留存 | ≥ 35% |
| D7 留存 | ≥ 12% |
| 分享率（分享行为/DAU） | ≥ 8% |
| 分享回流率 | ≥ 15% |
| 激励视频人均观看 | ≥ 2.5 次/日 |
| 单局平均时长 | 3–4.5 min |

## 二、叙事与话题性

### 2.1 世界观背景设定

**永夜纪元**：上古神话中，烛龙睁眼为昼、闭眼为夜。千百年前烛龙"死去"（真相 later 揭晓：是自囚），世间进入一场没有尽头的黑夜。人类在残存的**灯油矿脉**上建起绿洲城邦，以"灯台阵列"驱散黑暗、守护最后一盏文明之火。

长夜之下，黑暗并非虚无——它会孕育**晦兽**：以光为仇、以恐惧为食的黑影生物。晦兽强度随"夜龄"（黑夜进行的年数）增长，兽潮一浪高过一浪。

- **灯油**：唯一战略资源，既是塔的能量来源也是城邦命脉——剧情与数值同源（灯油枯竭 = 玩法失败条件）。
- **守灯会**：人类最强组织，垄断灯油矿脉与灯塔技术，信条"光前无暗"。
- **归夜教**：信奉"长夜即归宿"的地下教团，认为人类是烛龙尸身上的寄生虫。中后期揭示：他们接触到了部分真相。
- **拾遗人**：游走在黑暗荒野的 salvage 猎人，主角出身。

一句话世界规则：**光是武器，也是货币，更是信仰；而黑暗不一定站在错的对面。**

### 2.2 核心冲突（三层递进）

1. **生存层（第 1–3 章）**：兽潮压城，守灯。表层玩法冲突，教学期载体。
2. **真相层（第 4–6 章）**：灯油矿脉实为"烛龙之血"的凝结；守灯会高层早已知道，并隐瞒了矿脉将在一代人内枯竭的事实。主角的兄长**夜无面**在一次矿脉事故中被晦兽"带走"——归来时已是晦兽之主。
3. **立场层（第 7–9 章）**：杀烛龙则永夜终结、但依赖灯油的城邦文明同归于尽；唤醒烛龙则重见天日、但烛龙的"醒来"意味着人类如尘。归夜教与守灯会各自走向极端答案。**主角（玩家）的选择决定结局。**

### 2.3 角色设定

|---|---|---|---|
| **阿照** | 主角，16 岁见习点灯人 | 烈性子上头快，嘴硬心软；继承亡父的裂芯旧灯（贯穿剧情的关键道具） | 玩家化身；新手期唯一"英灵塔" |
| **夜无面**（原名"更"） | 反派 → 阵营摇摆者，阿照兄长 | 温柔克制，被晦兽侵蚀后失去面容，成了晦兽潮的"号令者"；每次兽潮首领战他都出现又退走 | 每章 Boss 关剧情演出；归夜线可转化为最强英灵 |

## 三、玩法系统

### 3.1 核心循环

```
战前侦察（15s）      看到波次预告/敌方暗性构成/地图光路骨架 → 决定带哪些图纸
   ↓
布阵备战（自由暂停）  放主灯、接光束、摆棱镜——本质是"画光路"
   ↓
波次战斗（3-4min）    自动战斗 + 手动"拨灯芯"爆发技（每局限 3 次）
   ↓                    第 5 波"夜幕加深"阶段变换：光效衰减，需临时改路
结算                   星级 / 灯油 / 图纸碎片 / 剧情碎片
   ↓
养成                   天赋树 / 英灵升级 / 城市重建（挂机产出灯油）
   ↓
新关卡 / 新剧情 / 社交动作（晒布局、借英灵、阵营贡献）
```

- **上手**：前三关只教"放灯→照路→杀晦"三件事；棱镜折射在第四关作为"惊喜机制"发放。
- **深度**：光路连通性 + 折射角度 + 三原光克制 + 夜幕加深改路 = 四层策略叠加，高手可追求"一灯通关"（只用一盏主灯的光路清场）等极限布局。

### 3.2 核心机制：光路与折射（本作的"一句话玩法"）

1. **主灯**发出光束（锥形或直线），晦兽进入光照范围持续受损——光是伤害，也是"视野货币"（未被照到的格子不可建塔，黑暗会滋生小晦）。
2. **棱镜塔**改变光束方向并分光：白光可折为红/黄/蓝三色光；三色光合流可成"环"（大范围净化）。
3. **光路连通**：光束首尾相连形成贯通网络时，共享增益（+15% 强度），鼓励整体设计而非孤立摆塔——这是与所有传统塔防的本质区别。
4. 表现层：玩家屏幕上最终呈现的是一张"光的管网"，布局千图千面 → 天然的晒图素材。

### 3.3 塔（灯）的分类

| 家族 | 定位 | 代表单位 | 升级方向（三选一分支） |
|---|---|---|---|
| **主灯系** | 光源/能量核心，每关限 1–2 座 | 行灯、城灯、烛龙灯（后期） | 亮度 / 光距 / 灯油耗 |
| **光束系** | 输出塔，需接入光路才有火力 | 焰矛（红）、霜针（蓝）、耀斑（黄） | 单体 / 溅射 / 穿透 |
| **棱镜系** | 辅助：折射、分光、合光、传导 | 三棱镜、曲率镜、聚光环 | 角度自由 / 自动寻路 / 增亮 |
| **阵法系** | 区域控制 | 灯界（减速域）、净火圈、影牢 | 控场 / 持续伤 / 破甲 |
| **英灵系** | 角色塔（养成线载体），主动技能 | 阿照、未眠、夜无面、桓青… | 与角色卡绑定，见 3.6 |

### 3.4 敌我克制（三层克制链）

**第一层·暗性（敌）× 光色（我）**——猜拳式，一眼可懂：

| 晦兽暗性 | 特征 | 克制光 | 被克表现 |
|---|---|---|---|
| 雾晦 | 群体、穿塔、雾态 | 焰光（红） | 点燃雾化，连锁蔓延 |
| 奔晦 | 高速、绕路 | 霜光（蓝） | 凝霜减速、可被冻断在光路上 |
| 甲晦 | 重甲、正面硬吃 | 耀光（黄，破甲） | 照甲显裂、白光合流可一击碎甲 |
| 无明（中立精英） | 三色皆抗 | 仅"合光环"与英灵技能有效 | Boss 级压力源 |

**第二层·光路依赖**：敌人会攻击/遮蔽光路节点（"蚀光灯蛾"专吃棱镜），迫使玩家预留冗余光路。
**第三层·阶段克制**：夜幕加深后敌方出现"噬光者"，未连通的光路段会被逐个熄灭——只有连通网络幸存。

### 3.5 关卡与波次设计

- **波次模板**：普通关 8–10 波、Boss 关 5 波 + 1 Boss 波、无尽夜潮（选做模式）。
- **单关节奏公式**（普通关 10 波为例）：
  - 波 1–2 低压（教学/确认布局）→ 波 3 小峰（混合暗性登场）→ 波 4 休息波（补给/改阵窗口）→ **波 5 夜幕加深**（全局光效衰减 20%，阶段变换点）→ 波 6–7 压力爬升（蚀光灯蛾咬光路）→ 波 8 伪高潮（精英无明）→ 波 9 极限（要求二次改路）→ 波 10 总攻（大波团 + Boss 小弟）。
- **地图骨架**：每张图预置"光位节点"（可建格）+ 天然折射面（岩壁镜面）+ 暗渊（不可照区，绕路压力）。同图在星级挑战下开放"变异规则"（如：全图仅 1 座主灯）。
- **失败保护**：漏怪只扣灯油，灯油归零才败；一关最多 3 次即时续关（看广告/道具），避免 3 分钟努力清零的挫败。

### 3.6 成长与养成模块

| 模块 | 内容 | 定位 |
|---|---|---|
| **灯芯天赋树** | 三系（明/透/燃）× 40 节点，用剧情碎片+灯油解锁 |  Build 自由度，重玩价值 |
| **图纸收集** | 塔的新皮肤形态=新图纸（部分附带微机制差异），碎片合成 | 收集欲 + 关卡产出多样性 |
| **英灵养成** | 角色卡（抽/碎片/阵营奖励），等级、技能、羁绊（兄妹/师徒） | 长线目标 + 剧情联动（选阵营直接影响可得英灵池） |
| **绿洲城建** | 用星级与灯油重建城邦建筑，被动产出灯油、解锁商店/功能建筑 | 挂机缓冲 + 叙事可视化（城随剧情被战火摧毁又重建） |
| **图鉴** | 晦兽图鉴（老烛笔记口吻）、剧情碎片回看 | 补全主义者的钩子 |

养成数值追求"浅曲线"：前 7 日每天均可解锁 1 个新单位/新机制，杜绝数值墙劝退。

### 3.7 单局时长控制（小程序端硬性设计）

| 场景 | 时长预算 | 手段 |
|---|---|---|
| 普通关 | 3–4 min | 波次间隔自动加速（2x/3x 已通关卡一键跳过） |
| Boss 关 | ≤ 6 min | 战斗阶段上限 5:30，超时按灯油余量判负，逼输出检查 |
| 剧情节点 | ≤ 60 s | 可跳过；对话带"快进"按钮 |
| 无尽夜潮 | 单人 ≤ 10 min 自动结算 | 防沉迷+防肝设计 |
| 每日总游戏 | 软上限 40 min | 达到后灯油产出衰减提示，不硬锁 |

### 3.8 社交玩法系统

- **好友榜（开放数据域）**：不比"战力"，比**"光半径"**（守下的城市亮圈面积），榜单本身是一张会长大的世界地图。
- **双灯合守**：异步协作——在好友的关卡里驻留一座自己的"英灵灯"（好友离线也可获得增益；借出方得谢礼）。
- **阵营贡献 & 世界大夜潮**：见 2.5。
- **分享装置**：布局海报（自动生成带光路美感的战报图）、剧情人格卡、结局卡、求助灯。所有分享点必须"给玩家一个炫耀/表达的理由"，禁止纯功能乞讨式分享。

## 四、美术与表现

### 4.1 整体风格定位

**"暖光手绘城邦 × 皮影英灵 × 剪影晦兽"**——三种工艺对应三类对象，风格统一于"光影叙事"：

- 基调：暗夜蓝 `#10182B` 为纸，暖灯金 `#F5B942` 为魂，灯芯白 `#FFF3D6` 为点睛；辅助色仅红`#E4572E`/蓝`#4A90D9`/黄`#F2C14E` 三束"光色"，全游戏色彩体系即玩法体系。
- 情绪配方：90% 黑蓝压境 + 10% 暖光不死——"黑暗越大，光越动人"。
- 风格参考：吉卜力的光氛 × 中国皮影/剪纸的轮廓艺术 × 绘本水彩的背景。UI 全部圆角"灯器"造型（灯盏、灯罩、灯芯）。

### 4.2 角色与场景呈现方式

| 对象 | 呈现方式 | 性能考量 |
|---|---|---|
| 晦兽 | 纯剪影 + 描边辉光 + 红瞳 | 单片网格 + 共享发光材质，DC 极低；剪影规避骨骼绑定成本 |
| 英灵 | 皮影风：侧面关节剪纸造型，Spine 骨骼动画 | 每英灵一张图集；待机 3 帧循环、出场 8 帧高光动作（成本集中花在刀刃） |
| 塔/灯 | 手绘物件 + 程序化火焰（shader 扰动） | 光晕不画帧动画，用径向渐变 + noise |
| 场景 | 分层水彩背景（远山剪影层可平移制造视差）+ 前景可建区 | 地图 = 3–5 张静态大图层，运行时零重建 |
| 剧情播片 | 竖版连环画（插画 + 文字气泡 + 镜头推移） | 复用 UI 图集，比 Live2D 省 10 倍成本 |

### 4.3 特效规范

- **光效三件套**（全游戏光效由此组合）：径向灯晕（shader）、体积光带（定向渐变网格条）、丁达尔尘（低频粒子，低端机自动关闭）。
- 克制反馈必须清晰可读：雾晦被点燃=橙色粒子拖尾；霜晦冻断=蓝白结晶碎裂；甲晦碎甲=金片爆散。任何克制生效需在 0.3s 内可视辨识。
- **同屏粒子上限 60**，超标时降级为贴图闪白；伤害数字默认关闭（可选开）。
- 夜幕加深转场：全场灯光压暗 + 环境音"呼吸感"低频，1.5s 完成，不用黑屏。

### 4.4 UI 设计规范

**组件语言**：一切控件皆"灯器"——按钮是灯座、弹窗是灯罩展开、进度条是灯油刻度。

| 模块 | 规范 |
|---|---|
| **图标** | 48/72 px 双规格栅格；线性 3 px 描边 + 内部单色填充；统一"光点"母题（每个图标含至少一处 `#F5B942` 光元素）；晦兽图鉴图标一律剪影化 |
| **按钮** | 主按钮"燃芯"（暖金渐变 + 外发光，按下火焰摇曳）；次按钮"未燃芯"（灰蓝描边，hover 点亮）；尺寸 ≥ 88×44 pt 触摸区；禁用态=熄灭带烟 |
| **弹窗** | 三段式：灯罩上滑展开 → 内容分层入场（标题→图文→按钮，间隔 60ms）→ 关闭时缩回。确认类弹窗必须双选项左右对称（呼应"两难抉择"母题） |
| **结算页** | 星级→灯油→碎片三行依次点亮（节奏 300ms）；顶部本关光路缩略图回放 2s（晒图按钮直达）；新增"本局数据卡"：照破晦数/最长光路/一次点亮塔数，全部为分享素材优化 |
| **字体** | 标题：定制艺术字（图片化，仅 40 个高频字）；正文：思源黑体 Bold/Regular 子集化；数字：等宽，克制触发时弹跳 |
| **动效总则** | UI 动效 ≤ 300ms；游戏内反馈 ≤ 150ms；全部 ease-out；低端机一键降级静态 |

### 4.5 音频方向

- 主乐器：箫 + 大提琴 + 灯芯燃烧的白噪；战斗 BPM 随波次 80→120 渐进，夜幕加深瞬间全部乐器抽走只留心跳。
- 音效层级：光路接通时"风铃"音（正反馈核心音，要悦耳到愿意反复接路）；所有克制音共用同一音阶家族。
- 包体：OGG 96kbps 音效总预算 < 8 MB（远程加载），点灯开场音必须内置主包。

## 六、可执行结论

1. **立项判断：Go，但以 P0 原型为生死线。** "光路折射塔防"的机制差异化 + 剪影美术的传播性，符合小游戏"三秒抓人、三分钟一局、一张图能说清"的爆款公式；最大不确定性不是市场而是"接光路是否真的好玩"——因此**先用 2 周只做灰盒原型，数据（复玩率/主动分享灰盒截图的意愿）说话，再投入垂直切片**。
2. **首发范围锁定**：上线即开第 1–6 章（约 3.5 小时内容 + 40 分钟日常），7–9 章与隐藏结局按周解锁，保证 4 周内容曲线与话题热度（阵营公投定在买量/裂变最高峰的第 3 周开启）。
3. **商业线锁定**：首发纯 IAA（激励视频四点位：复活/双倍/刷新/续夜油），Android IAP 后置。不做抽卡付费（英灵只靠剧情/阵营/广告碎片获取），保护叙事纯粹性与合规面。
4. **不可妥协的三个体验红线**（任何排期压力不得牺牲）：
   - 首屏 3 秒"黑暗→点灯"冲击序列常驻主包；
   - 普通关单局 ≤ 4 分钟 + 已通关卡一键跳过；
   - 光路接通的"风铃音 + 亮路"反馈必须打磨到玩家想反复听。
5. **近期行动清单（决策后 30 天）**：
   - 周 1：组建 5 人核心组；启动软著材料与小游戏类目资质；M2 光路 Shader 原型。
